# Release Notes

## v0.1.0 — 2026-08-25

First versioned GitHub source release of SeqReg.

- Adds Python package metadata so the repository can be built and installed
  directly from a pinned Git tag.
- Removes Python standard-library modules from `requirements.txt`.
- Pins the source snapshot used by this release to its Git tag and commit.

This release contains code and documentation only. Training data and pretrained
weights remain separately hosted or subject to their stated terms. The release
does not establish cross-laboratory validation, a new benchmark, or deployment
readiness.
